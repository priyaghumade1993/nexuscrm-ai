# NexusCRM AI — Labs

Supplementary technology explorations that demonstrate breadth beyond the core project.

Each lab is a self-contained Python script or notebook demonstrating a specific technology
in the context of CRM data.

## Labs

| Lab | Technology | File |
|-----|-----------|------|
| 01 | MySQL comparison with PostgreSQL | `mysql_comparison.py` |
| 02 | JavaScript/TypeScript API client | `js_api_client/` |
| 03 | HuggingFace model exploration | `huggingface_embeddings.py` |
| 04 | PyTorch lead scoring model | `pytorch_lead_scoring.py` |
| 05 | TensorFlow churn prediction | `tensorflow_churn.py` |
| 06 | Scikit-learn pipeline value prediction | `sklearn_pipeline_forecast.py` |
| 07 | Power BI SQL views | `powerbi_views.sql` |
| 08 | Alternative LLM providers (conceptual) | `alternative_providers.md` |

## How to Run

Each lab is self-contained. Most require only:
```bash
pip install <requirements in lab file header>
python labs/<lab_file>.py
```
